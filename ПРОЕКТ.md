## Что это

Переводчик для меню-бара macOS. Бесплатный:
Google Translate (неофициальная точка, без ключей) + офлайн-движок Apple
Translation. 12 языков, история, озвучка, лимит символов, свои иконки.
Пользователь — не программист, общение по-русски, объяснять просто.

## Сборка и запуск

```bash
cd path/to/translator
./build_app.sh          # swift build -c release → Translator.app + подпись
open Translator.app
```

- Иконка приложения генерируется `swift make_icon.swift` → `AppIcon.icns`
  (build_app.sh делает это сам, если файла нет; после правок дизайна — удалить
  icns и пересобрать).
- Перезапуск: `pkill -x Translator; open Translator.app`.

## Подпись (ВАЖНО)

- `build_app.sh` ищет первый доступный сертификат `Apple Development`.
- Если сертификат не найден, используется ad-hoc подпись.
- Для стабильных Accessibility-разрешений лучше использовать постоянный
  Apple Development или Developer ID сертификат.

## Права и системные интеграции

- **Универсальный доступ** (Accessibility): выдан приложению для имитации ⌘C
  (хоткей ⌃⌥T). Привязан к подписи сертификатом — стабилен.
- **Системная служба** «Перевести выделенный текст» (NSServices в Info.plist,
  NSMessage `translateSelectedText`, обработчик в AppDelegate). Сочетание
  ⇧⌘E задано и через plist (NSKeyEquivalent = E), и перекрыто в
  `defaults write pbs NSServicesStatus` (ключ
  `"org.free-translator.macos - Перевести выделенный текст - translateSelectedText"`,
  `key_equivalent = "@$e"`). Обновление кэша служб:
  `/System/Library/CoreServices/pbs -flush` (есть в build_app.sh).
- **Автозапуск**: SMAppService.mainApp (переключатель в настройках).
- **UserDefaults** (домен org.free-translator.macos): `selectionHotkey`,
  `clipboardHotkey` (словари keyCode/modifiers/display), `autoTranslate`,
  `appTheme` (`neonGlass` / `frostGlass`, старые `mindora` / `liquidGlass`
  мигрируют при чтении), `history` (JSON, до 10 записей), `offlineUpdateLastCheck`,
  `offlineInstalledLanguageCodes`, `migratedSelectionToService` (флаг старой
  миграции, не трогать).

## Горячие клавиши (текущая раскладка)

| Сочетание | Действие | Механизм | Права |
|---|---|---|---|
| ⌃⌥T | Перевести выделенное | Carbon-хоткей → имитация ⌘C (CGEvent) | Универсальный доступ |
| ⇧⌘E | Перевести выделенное | Системная служба macOS | не нужны |
| ⌃⌥C | Перевести из буфера | Carbon-хоткей | не нужны |

⌃⌥T и ⌃⌥C переназначаются в настройках приложения (рекордер сочетаний).

## Тестовые режимы (CLI, бинарник из .build)

```bash
./.build/release/Translator --test-translate "hello"      # онлайн Google
./.build/debug/Translator   --test-offline                # статусы офлайн-языков
./.build/debug/Translator   --test-apple "hello"          # офлайн-перевод (откроет окошко)
./.build/release/Translator --test-service "hello"        # доставка через службу
```

## Грабли, о которых надо помнить

1. **Сочетания служб macOS срабатывают только с ⌘** — ⌃⌥-сочетания служба
   игнорирует. Поэтому у службы ⇧⌘E, а ⌃⌥T — Carbon-хоткей.
2. **Перед CGEvent-⌘C ждать отпускания модификаторов** (SelectionGrabber),
   иначе приложения видят «⌘⌃⌥C» и не копируют.
3. **Apple Translation работает только через .translationTask на видимом view.**
   Скачивание языков — только из обычного окна (не из панели: она закрывается
   и обрывает загрузку). Пары качаются «язык↔en», перевод любых пар — через
   опорный английский.
   Apple не отдаёт публичную версию языковой базы: проверка актуальности
   сделана через периодический `LanguageAvailability.status`. Если язык раньше
   был `installed`, а через неделю стал `supported`, показывается маленькое
   уведомление и пользователь сам решает, нажимать ли «Обновить».
4. **Google gtx**: текст в POST-теле (GET не влезает), лимит ~5000 символов,
   таймаут 8 с; при ошибке — fallback на Apple.
5. **NSPopover заменён на FloatingPanel** — не возвращать поповер: были
   проблемы с позицией и закрытием при системных диалогах.
6. Блокировать главный поток семафором нельзя, если API ходит через XPC
   (LanguageAvailability) — нужен живой run loop (см. --test-offline).
7. При открытых вспомогательных окнах панель остаётся видна позади
   (keepsVisibleBehindOtherWindows) и всплывает после их закрытия.
