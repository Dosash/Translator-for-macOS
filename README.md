# Translator-for-macOS
Бесплатный переводчик в строке меню macOS. Приложение переводит текст онлайн через публичную точку Google Translate и умеет использовать офлайн-перевод Apple Translation, если нужные языковые пакеты уже установлены в системе.  Проект распространяется бесплатно по лицензии MIT.
